📁 项目架构概览

本项目是一个基于 Scrapy 的分布式搜索引擎教学项目，包含四个核心模块：

🕷 ArticleSpider
Scrapy 爬虫项目，含 B站热门/每周必看/评论、豆瓣Top250、quotes演示站，支持 Playwright 渲染、LLM 抽取自愈、指纹头/代理中间件，数据写入 Elasticsearch。
🔍 LcvSearch
Django 后端，提供关键词搜索、RAG 问答（DeepSeek + numpy 向量库）、实时联邦搜索、爬虫任务管理等 JSON API，纯 API 架构对接前端。
⚡ ScrapyRedisTest
Scrapy-Redis 分布式爬虫演示，伯乐在线文章爬虫，使用 Redis 共享请求队列和去重过滤器，是课程分布式部分的教学示例。
🎨 frontend
Vue 3 + Vite + Element Plus 前端 SPA，包含搜索、榜单、AI问答、数据概览、采集管理五个视图，通过 API 与后端交互。
